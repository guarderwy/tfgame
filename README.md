# 前线防线 Frontline Defense

架空战争题材的 3D 网页塔防游戏原型。使用 Vite + TypeScript + Three.js 开发，纯前端、无后端依赖。

玩家在陆地空地部署武器抵御来犯的地面、空中、水路三路敌军，守护基地生命。30 个关卡逐步解锁更复杂的路线形态与更强敌种，末波为强化首领。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的地址（默认 `http://localhost:5173/`）即可。

其他命令：

```bash
npm run build     # 类型检查 + 生产构建，产物在 dist/
npm run preview   # 本地预览生产构建
npm run balance   # 离线模拟 30 关 × 3 种策略 × 5 个随机种子，校验难度与经济
```

## 操作

| 操作 | 说明 |
|---|---|
| 选武器 → 点击地图 | 在合法地块建造，建成后自动取消当前武器选择以免误点（水路/路线格不可建普通塔，水雷布设器需建在水边陆地） |
| 点击已建武器 | 选中并查看信息，可升级 / 出售 |
| 数字键 `1`–`9` | 按侧栏价格升序快速选择对应武器 |
| 右键 / `Esc` | 取消当前建造选择 |
| `Q` / `E` | 左右旋转视角（也可点顶栏按钮） |
| `R` | 为选中的炮塔轮换索敌优先级 |
| 滚轮 | 缩放视角 |
| `空格` | 开始下一波 |
| `F` / 顶栏“标准屏 / 宽屏” | 在默认 16:10 与 16:9 宽屏间切换，选择会保存在本地 |
| 顶栏按钮 | 关卡选择、倍速（1x/2x）、暂停、音乐/音效开关、高对比模式、视角重置 |

击杀敌人获得金币；敌人抵达基地则扣除基地生命，生命归零失败；守住全部波次即通关。

## 武器系统

9 种武器，每种 3 级。升级按固定倍率提升伤害、射程、射速。

武器按当前选择的关卡解锁（切换关卡时即时生效，重玩旧关只可使用该关卡已解锁的武器）：

| 解锁关卡 | 武器 |
|---|---|
| 第 1 关 | 机枪炮台 |
| 第 2 关 | 榴弹炮 |
| 第 3 关 | 岸防炮、水雷布设器 |
| 第 5 关 | 防空炮 |
| 第 7 关 | 激光炮 |
| 第 9 关 | 防空爆破炮 |
| 第 11 关 | 电弧塔 |
| 第 13 关 | 电磁轨道炮 |

| 武器 | 定位 | 目标 | 特性 |
|---|---|---|---|
| 机枪炮台 | 廉价高射速 | 地面 | 克制步兵、轻甲 |
| 榴弹炮 | 范围爆炸 | 地面 | 溅射 44，克制集群 |
| 防空炮 | 高速拦截 | 空中 | 单体高射速、射程 150，专打飞机/无人机 |
| 岸防炮 | 重型远程 | 水路 | 溅射 22，主力反舰 |
| 激光炮 | 高频能量束 | 地面/空中 | 射速 7.5/秒 |
| 防空爆破炮 | 空中范围爆炸 | 空中 | 溅射 58，克制机群 |
| 电磁轨道炮 | 超远射程 | 地面/水路 | 无视护甲 |
| 电弧塔 | 闪电连锁 | 地面 | 最多连锁 3 个目标 |
| 水雷布设器 | 水路陷阱 | 水路 | 建在水边陆地，定时向最近水路布雷；船触碰引爆，1/2/3 级分别同时布 3/4/5 颗，炸一颗隔一周期补一颗 |

**水雷布设器补充**：布雷周期约 2.5 秒，单雷伤害 45、爆炸半径 52；无水路的关卡无法建造。它是唯一"投放实体陷阱"的武器，其余武器均发射投射物直接攻击。

### 索敌优先级
点击已建炮塔，在详情面板切换「最前 / 最近 / 残血 / 高血 / 高赏金」，每座塔独立生效；同类型新塔会沿用上次选择（本地保存）。默认「最前」保持原有行为。水雷布设器布设实体陷阱，不参与索敌。

### 视觉识别
每类武器在 `TOWER_CONFIG` 中配置 `body` / `secondary` / `pattern`，生成明亮双色装甲纹理；炮管为副色、骨架为中灰，不再整体压暗。底座保留同色发光识别环，下方用细小白色点数表示等级（一级一个点）。激光炮子弹为向目标端收束的细窄聚焦光束。敌方单位沿用同一材质语言，按种类保留专属轮廓并补充灯带与结构细节，机械与能量单位的灯带会轻微脉冲。夜战关卡自动提高发光；系统菜单的「高对比」模式会提高曝光与色标亮度。

## 敌人系统

13 种敌人，按路线分三类，每种有独立生命、速度、护甲、赏金与基地伤害：

- **地面**：步兵、装甲车、坦克、机甲、步行者
- **空中**：飞机、无人机、武装直升机、轰炸机
- **水路**：舰船、气垫船、潜艇、驱逐舰

每类敌人的克制建议在游戏内"敌人图鉴"中可查，例如重甲目标适合轨道炮穿甲、机群适合防空爆破炮范围伤害、高速潜艇适合高射速岸防炮等。

## 关卡与波次

- 30 个关卡，路线形态差异明显：S 形、锯齿、回环、迷宫、分叉、多地面/多水道并行等；第 3 关首次出现水路，第 7 关分岔，第 16 关三地面，第 20 关三地面三水道，第 21–30 关在三路混编基础上继续加大路线密度与混编强度。
- 30 关的完整布局与每一条地面/水道路线均经过去重校验，没有复用同一条路线。
- 30 套主题配色：草原、山谷、河网、丛林、港口、铁路、河口、夜战、要塞、荒漠、雪原、城市、深水、峡谷、宇宙空间站等。
- 统一渐进波次生成器：按地面/水路/空中三条路线分组选兵，保证有水必有水军；多路线关卡按路线数量分摊每波敌人总数，避免总压力翻倍；首波为基础单位，之后逐波增强，末波为强化首领（更大体型、皇冠与专属血条）。
- 每关独立配置初始金币与基地生命，敌人属性随关卡按 `1 + (关卡 - 1) × 0.038` 成长，并叠加逐关兵力/生命/首领微调；首领血量按关卡单独放大，并设早期下限，避免高威胁低血量兵种当首领时过脆。
- 经济曲线同步收紧：清波奖励为 `16 + 关卡`、提前出击奖励 8 金币，避免中后期金币过剩。

## 数值机制

配置集中在 `src/config.ts`，便于调整平衡：

- **护甲**：百分比减免 `伤害 × (1 - 护甲 / (护甲 + 50))`；轨道炮等穿甲武器无视护甲。
- **升级**：伤害 ×1.4、射程 ×1.1、射速 ×1.08，最高 3 级；升级费随等级递增。
- **出售**：返还累计投入的 60%。
- **经济**：击杀赏金随敌人强度与关卡缩放；每波清完有额外奖励。
- **难度**：敌人生命倍率随关卡线性增长，Boss 波单独加成。

`npm run balance` 会复现建造、索敌、投射物、护甲、水雷与波次结算，按“保守 / 普通 / 高手”三种策略逐关跑多个随机种子。验收目标是普通策略 30 关全胜、剩余生命约 30%–70%、满星率不高于 35%，高手策略稳定通关；可用 `BALANCE_FROM` / `BALANCE_TO` / `BALANCE_SEEDS` 缩小验证范围。

## 技术结构

纯 TypeScript + Three.js，Vite 构建，所有美术为运行时程序化生成的低多边形几何体，无外部素材。

```
src/
  config.ts      地图/数值配置：敌种、武器、升级倍率、难度成长
  types.ts       静态类型定义
  gameTypes.ts   运行时实体类型：塔、敌人、投射物、水雷、特效、粒子
  levels.ts      30 关路线、主题与波次配置
scripts/
  balance.ts     离线平衡模拟：逐关验证胜率、剩余生命、满星率与金币结余
  weather.ts     主题天气效果：雨、雪、雷暴、粒子与天空光调整
  renderer3d.ts  Three.js 场景、单位/塔/水雷模型、特效与粒子渲染
  audio.ts       Web Audio 程序化音效与背景音乐
  game.ts        核心逻辑：建造、寻敌、战斗、经济、波次、UI 绑定
  main.ts        入口
```

渲染优化：路径地块、围墙、装饰物使用 `InstancedMesh` 批量绘制；投射物按武器类型生成专属造型，并在生命周期结束时释放。特效（冲击环、光束、电弧、闪光）与粒子池化管理。

音效全部由 Web Audio 合成，可独立开关音乐与音效。
