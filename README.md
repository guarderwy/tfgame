# 前线防线 Frontline Defense

架空战争题材的 3D 网页塔防游戏原型。使用 Vite + TypeScript + Three.js 开发，无后端依赖。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的地址即可。生产构建：`npm run build`。

## 当前内容

- 20 个关卡，路线从简到繁重绘：第 1 关直线教学 → 第 3 关水路 → 第 7 关分岔 → 第 13 关双水 → 第 16 关三地面 → 第 20 关三地面三水道
- 每关路线形态差异化（S 形、锯齿、回环、蛇形、迷宫、分叉、多线并行），不是同一模板换色
- 全关卡使用统一渐进波次生成器：第 1 波仅 3–8 个基础单位，之后每波递增；关数越高波次越多、敌人越强，末波为强化 Boss 波
- 20 套独立主题：草原、山谷、河网、丛林、港口、铁路、河口、夜战、要塞、荒漠、雪原、城市、深水、峡谷、宇宙空间站等
- 8 种可升级武器：机枪炮台、榴弹炮、防空炮、岸防炮、激光炮、防空爆破炮、电磁轨道炮、电弧塔（穿甲/连锁）
- 9 类低多边形 3D 模型：步兵、装甲车、坦克、飞机、舰船、机甲、无人机、气垫船、步行者，带血条、朝向、车轮/螺旋桨/腿部动画
- 炮弹发射后沿固定方向直线飞行，不再追踪或反弹
- 立体地形、主题装饰与基地模型、圆形攻击范围预览、水面微光
- 路径地块、围墙与装饰物使用 InstancedMesh 批量渲染，降低绘制调用
- 炮口火光、爆炸碎片、烟雾尾迹等粒子特效
- 滚轮缩放、Q/E 或按钮旋转视角、视角重置
- Web Audio 程序化音效：建造、升级、开火、爆炸、警报、胜负，可一键静音
- 金币经济、基地生命、波次自动/手动推进、倍速与暂停

## 目录

```
src/
  config.ts     地图与数值配置
  types.ts      静态类型定义
  gameTypes.ts  运行时实体类型
  levels.ts     20 关路线、主题与波次配置
  renderer3d.ts Three.js 立体场景、单位模型与粒子渲染
  audio.ts      Web Audio 程序化音效
  game.ts       核心游戏逻辑
  main.ts       入口
```
